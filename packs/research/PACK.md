# Research pack

Loaded on demand. Universal rules live in the kernel core and are not repeated here.

## Evidence that matters

Primary sources outrank summaries of them, and a summary you have not opened is a
rumor. When official documentation exists, community posts are corroboration, not
authority.

Record what would falsify each claim. A finding with no falsifier is an opinion
wearing a citation.

Search for what breaks before what works. The failure reports, the post-mortems,
and the closed issues carry more information per token than the landing page.

## Execution patterns

**direct** — a specific fact with a known source. Look it up, cite it, stop.

**gated** — a bounded question with a deliverable. Scope what counts as an answer
before searching, gather, then synthesize with each claim traced to its source.
The check is that a reader can follow every claim back.

**trajectory** — genuinely open inquiry where each finding reshapes the question.
Search, read, revise the question, search again. Stop when a round returns nothing
that changes the picture.

## Verification

Trace each claim to a primary source and name what would falsify it. Distinguish
what you read from what you inferred; mark the inferences.

Report uncertainty and sample size. One run is an anecdote. Contradicting sources
get reported as a contradiction, not silently resolved in favor of the tidier one.

State what you could not find. A gap named is a finding; a gap hidden is a defect.

## Hazards

- **Confirmation drift.** Searching for support rather than for truth. Deliberately
  run one query designed to prove yourself wrong.
- **Stale authority.** Documentation and benchmarks age. Date every source.
- **Laundering.** A claim repeated across three blogs that all cite the same
  original is one source, not three.
- **Synthesis without reading.** Summarizing abstracts produces confident mush.
- **Scope creep.** Open inquiry expands without limit. Name the stopping condition
  before starting.
